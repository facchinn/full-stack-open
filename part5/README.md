# Parte 5 — Blog List frontend

En esta parte continué Blog List desde el frontend y agregué las pruebas de React y end-to-end.

## Qué practiqué

- inicio de sesión y sesión persistente con `localStorage`
- componentes reutilizables
- formularios con componentes `Togglable`
- creación, likes y eliminación de blogs
- orden por cantidad de likes
- pruebas de componentes con Vitest y Testing Library
- pruebas end-to-end con Playwright

## Ejecutar

El frontend consume el backend de la Parte 4.

```bash
cd part5
npm install
npm run dev
```

Pruebas de componentes:

```bash
npm test
```

Pruebas end-to-end:

```bash
npm run test:e2e
```

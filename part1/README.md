# Parte 1 — Introducción a React

En esta parte practiqué los fundamentos de React con los tres ejercicios principales del curso:

- `courseinfo` — ejercicios 1.1 a 1.5
- `unicafe` — ejercicios 1.6 a 1.11
- `anecdotes` — ejercicios 1.12 a 1.14

Los dejé juntos en una sola app para poder revisar rápido los tres resultados, pero cada sección mantiene la lógica correspondiente a sus ejercicios.

## Qué practiqué

- creación y reutilización de componentes
- props
- estado con `useState`
- manejo de eventos
- renderizado de listas
- cálculos derivados del estado
- actualización de arrays sin mutarlos directamente

## Ejecutar

```bash
npm install
npm run dev
```

Después de levantar Vite, la aplicación queda disponible en la URL que aparece en la terminal, normalmente `http://localhost:5173`.

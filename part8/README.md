# Parte 8 — GraphQL

En esta parte construí la aplicación de biblioteca usando GraphQL, con backend y frontend separados.

## Estructura

- `server/` — Apollo Server, MongoDB, autenticación y suscripciones
- `client/` — React y Apollo Client

## Qué practiqué

- schemas, queries y mutations
- resolvers
- relaciones entre autores y libros
- autenticación con JWT
- Apollo Client
- caché y actualización después de mutaciones
- filtros y recomendaciones
- subscriptions en tiempo real

Para ejecutar la parte completa primero hay que configurar las variables del servidor a partir de `.env.example`, levantar el backend y después iniciar el cliente.

# Parte 7 — Router, hooks y Blog List

En esta parte trabajé routing, hooks personalizados y una versión más completa del frontend de Blog List.

## Qué practiqué

- React Router
- parámetros de URL y navegación programática
- hooks personalizados como `useField` y `useCountry`
- TanStack Query
- Context para notificaciones
- vistas de blogs y usuarios
- likes y comentarios
- autorización para eliminar blogs

Los ejercicios cortos de router y hooks están agrupados en la sección `Labs` y el resto de la aplicación continúa Blog List.

## Ejecutar

El frontend usa el backend de la Parte 4.

```bash
cd part7
npm install
npm run dev
```

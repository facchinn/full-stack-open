# Parte 10 — React Native

En esta parte desarrollé Rate Repository App con Expo y React Native.

## Qué practiqué

- componentes de React Native
- estilos con `StyleSheet`
- navegación
- formularios y validación
- Apollo Client
- autenticación persistente
- búsqueda y orden de repositorios
- paginación por cursor
- detalle de repositorios
- creación y eliminación de reseñas

## Ejecutar

Primero copio `.env.example` a `.env` y configuro `EXPO_PUBLIC_APOLLO_URI` con la URL de `rate-repository-api`.

```bash
cd part10
npm install
npm start
```

Mantuve esta parte fuera de los workspaces de la raíz para no mezclar las dependencias de Expo con los proyectos web.

# Parte 10 — Rate Repository App

Aplicación Expo/React Native con navegación, Apollo, autenticación persistente, lista ordenable y buscable, paginación por cursor, detalles, creación y gestión de reseñas.

1. Copia `.env.example` a `.env` y apunta `EXPO_PUBLIC_APOLLO_URI` a una instancia de `rate-repository-api`.
2. Ejecuta `npm install` y `npm start`.

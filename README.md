# Full Stack Open

Estoy usando este repositorio para ir subiendo los ejercicios de **Full Stack Open**, de la Universidad de Helsinki.

La idea es ir completando y enviando una parte a la vez, manteniendo cada grupo de ejercicios separado para que sea fácil de revisar.

## Parte 0

En esta parte trabajé lo básico del funcionamiento de una aplicación web: peticiones HTTP, respuestas del servidor, JavaScript en el navegador y la diferencia entre una aplicación tradicional y una SPA.

Los ejercicios `0.1`, `0.2` y `0.3` son de lectura. Los diagramas de `0.4`, `0.5` y `0.6` están dentro de `part0/`.

## Parte 1

En esta parte empecé con React y practiqué componentes, props, estado con `useState`, eventos y actualización de datos en la interfaz.

Los ejercicios están separados en tres aplicaciones:

- `courseinfo/` — ejercicios 1.1 a 1.5
- `unicafe/` — ejercicios 1.6 a 1.11
- `anecdotes/` — ejercicios 1.12 a 1.14

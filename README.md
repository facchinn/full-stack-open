# Full Stack Open

Este repositorio es donde voy guardando mis ejercicios de **Full Stack Open**, el curso de desarrollo web de la Universidad de Helsinki.

Por ahora dejé únicamente la **Parte 0** para enviar y registrar esta parte antes de continuar con las siguientes.

## Parte 0 — Fundamentos de aplicaciones web

En esta parte trabajé el funcionamiento básico de una aplicación web, las peticiones HTTP y las diferencias entre una aplicación tradicional y una SPA.

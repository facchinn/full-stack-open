# Full Stack Open

En este repositorio estoy guardando mis ejercicios de **Full Stack Open**, el curso de desarrollo web de la Universidad de Helsinki.

Por ahora dejé solamente la **Parte 1**, separando cada grupo de ejercicios en su propia aplicación para que sea más fácil revisar el código.

## Parte 1 — Introducción a React

```text
part1/
├── courseinfo/   # ejercicios 1.1 a 1.5
├── unicafe/      # ejercicios 1.6 a 1.11
└── anecdotes/    # ejercicios 1.12 a 1.14
```

En esta parte practiqué:

- componentes y props
- estado con `useState`
- manejo de eventos
- renderizado de listas
- actualización de arrays sin mutarlos
- cálculos a partir del estado

## Ejecutar un ejercicio

Cada aplicación se puede ejecutar desde su propia carpeta. Por ejemplo:

```bash
cd part1/unicafe
npm install
npm run dev
```

Lo mismo se puede hacer con `courseinfo` y `anecdotes`.

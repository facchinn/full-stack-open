# Parte 9 — TypeScript

En esta parte empecé a usar TypeScript tanto en ejercicios chicos como en aplicaciones con frontend y backend.

## Estructura

- `courseinfo/` — tipos, interfaces y manejo de datos del curso
- `flight-diary/` — aplicación de diario de vuelos con TypeScript
- `backend/` — backend de Patientor
- `frontend/` — frontend de Patientor

## Qué practiqué

- tipos primitivos y tipos propios
- interfaces y uniones
- type narrowing
- validación de datos recibidos
- TypeScript con Express
- React con TypeScript
- formularios tipados
- manejo de errores desconocidos

Cada proyecto tiene su propio `package.json` y se puede ejecutar desde su carpeta.

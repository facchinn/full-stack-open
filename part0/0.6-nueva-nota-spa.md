# 0.6 — Nueva nota en una SPA

En la SPA el formulario no provoca una recarga completa. JavaScript intercepta el envío, crea la nota, actualiza la lista que se ve en pantalla y después manda la nueva nota al servidor como JSON.

```mermaid
sequenceDiagram
    participant browser as Navegador
    participant server as Servidor

    Note right of browser: El usuario escribe una nota y presiona Save
    Note right of browser: JavaScript evita el envío normal del formulario
    Note right of browser: Crea la nota, la agrega a la lista y vuelve a dibujarla

    browser->>server: POST /exampleapp/new_note_spa con JSON
    activate server
    Note right of server: El servidor guarda la nota
    server-->>browser: 201 Created
    deactivate server

    Note right of browser: La página sigue abierta, sin redirección ni recarga
```

La parte que más cambia con respecto al ejercicio 0.4 es que no aparece un `302` ni un nuevo `GET` de la página. La vista se actualiza directamente desde JavaScript.

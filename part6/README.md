# Parte 6 — Gestión de estado

En esta parte practiqué distintas formas de manejar estado global y datos del servidor.

## Ejercicios incluidos

- Unicafe con Redux
- Anecdotes con Redux Toolkit
- Anecdotes con TanStack Query y Context

## Qué practiqué

- reducers y actions
- Redux Toolkit y `createSlice`
- React Redux
- thunks
- filtros y notificaciones
- TanStack Query
- mutaciones y actualización de caché
- Context para estado compartido

Para los ejercicios que usan JSON Server:

```bash
cd part6
npm install
npm run server
```

Y en otra terminal:

```bash
npm run dev
```

Dejé un selector dentro de la aplicación para poder revisar las distintas soluciones sin mezclarlas en la lógica de cada ejercicio.
